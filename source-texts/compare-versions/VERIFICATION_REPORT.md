# Comparison Versions — Verification Report

Generated by `build_compare_migration.py` from the staged public-domain
sources in `raw/`. Every version's book / chapter / verse counts are
checked against the known canonical counts, and the 66-book versions are
diffed verse-by-verse against the KJV reference set. Accuracy is the
wedge — rival apps fail at exactly this (missing chapters, mislabeled
verses, books advertised but absent), so every gap is called out.
